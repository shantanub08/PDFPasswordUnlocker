# Product

## Register

product

## Platform

web

## Users

Individuals and professionals needing quick, 100% private PDF password removal without uploading sensitive documents to external cloud servers.

## Product Purpose

Provide a fast, secure, and client-side web application that decrypts PDF files directly inside the browser using WebAssembly (`qpdf.js`), replacing legacy CLI scripts and avoiding privacy risks associated with cloud converters.

## Positioning

Instant, zero-server-upload PDF password removal running entirely inside your browser via WebAssembly.

## Brand Personality

Trustworthy, sleek, precise. Features modern design aesthetics with support for both dark and light modes, subtle glassmorphism, and clear interactive state indicators.

## Anti-references

Generic SaaS white layouts with default blue accents, clunky file dropzones, intrusive modals, and confusing multi-step wizards for single-action tasks.

## Design Principles

- Privacy-First Transparency: Visually reinforce local processing and security so users feel completely safe handling confidential files.
- Frictionless Workflow: Keep the core unlock path effortless—drag & drop, enter password, and auto-download without unnecessary steps.
- Premium Tactile Precision: Deliver crisp typography, purposeful micro-animations, clear focus states, and dual light/dark theme adaptability.

## Accessibility & Inclusion

Target basic WCAG A compliance with high text contrast, full keyboard navigation, and explicit visual focus rings.
